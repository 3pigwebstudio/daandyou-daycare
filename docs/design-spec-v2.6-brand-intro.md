# v2.6 브랜드 인트로 설계

## 목적

홈페이지 첫 방문에서 로고와 공식 기관명을 먼저 인지시키고, 전문적이고 세심하게 관리되는 시설이라는 첫인상을 만든다. 넷플릭스처럼 브랜드를 먼저 보여주는 진입 구조를 사용하되 시각 표현은 애플 스타일의 절제된 여백, 정밀한 타이포그래피, 부드러운 감속 모션으로 구성한다.

## 화면과 모션

1. 깨끗한 흰색 전체 화면에서 다앤유 공식 로고가 선명해진다.
2. 얇은 청록색 선이 짧게 확장된다.
3. `강서다앤유재활 데이케어센터`와 영문 보조 문구가 차분하게 나타난다.
4. 약 1.58초 후 인트로가 사라지고, 랜딩페이지가 흐림 없이 또렷하게 열린다.
5. 전체 체감 시간은 약 2.3초 이내다.

## 이용 편의 원칙

- 같은 브라우저 세션에서는 최초 1회만 재생한다.
- 특정 섹션 링크로 바로 접속하면 인트로를 생략한다.
- `바로 보기` 버튼으로 즉시 건너뛸 수 있다.
- 운영체제의 모션 감소 설정이 켜져 있으면 인트로를 표시하지 않는다.
- 로고를 불러오지 못하면 텍스트 워드마크를 표시한다.
- 사운드, 입자, 강한 회전, 튕김 효과는 사용하지 않는다.
