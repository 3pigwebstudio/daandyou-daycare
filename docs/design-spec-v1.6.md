# 강서 다앤유 재활 데이케어센터 — v1.6 통합 UX 설계 기준

## 버전 정보
- 기준: v1.5 승인본의 **3개 모바일 내비게이션 + 데스크톱 Editorial Landing** 구조 유지
- v1.6 변경 범위: **모바일·데스크톱 50대 이상 중심(가설) UX 가독성/터치 영역/상담 접근성**
- 50대 이상의 디지털 역량을 획일적으로 가정하지 않으며, 모든 연령에게 이해하기 쉬운 Inclusive UX를 지향
- 배포 상태: **로컬 구현 시안**, 실제 운영 배포 전

## UX 목표
- 보호자의 의사결정 흐름: **신뢰 → 적합성 → 이용 가능성**
- 사용자에게 3가지 질문을 직접 노출하지 않고, 정보구조·콘텐츠·문의 기능으로 질문을 해소
- 어느 주요 화면에서든 **최대 3클릭 이내 전화 연결 동작**, 모바일은 **고정 CTA 1탭** 목표

## 1. 유지되는 디자인/브랜드
- 공식 다앤유 마스터 로고: 2025-11 승인 이미지 URL `https://cdn.imweb.me/thumbnail/20251118/380d41f33f811.png` (로고 자체 임의 재제작 금지)
- 컬러: Primary `#206E88` / Deep Navy `#193249` / Soft Sky `#D8EAF3` / Charcoal `#27343B` / Cool White `#F7F9FA`
- 모바일 홈의 3개 메뉴: **다앤유 소개 / 전문 프로그램 / 이용 및 위치 안내**
- 모바일 프로그램 카드: 식이·연하 지원, LSVT BIG 기반 움직임, 인지·일상 활동, 함께하는 하루
- 데스크톱: Hero + 브랜드 신뢰 + 2대 특화 프로그램 + 일상 + 전문인력 + 안내/상담 순서 유지
- 사진은 콘셉트 시안이며 실제 시설/인물 사진으로 표현하지 않음

## 2. v1.6 UX 규격(프로젝트 목표)
| 항목 | 모바일·태블릿(850px 이하) | 데스크톱(851px 이상) |
|---|---|---|
| 주요 본문 | 17–18px, 최소한의 보조 라벨만 13–16px | 주요 설명 18–19px, 보조/운영주석 15–17px |
| 헤드라인 | 메인 29–40px / 상세 32–43px | 섹션 36–52px |
| 주요 CTA | 고정 하단 60px 이상 | 헤더 56px, 일반 버튼 56px 이상 |
| 프로그램 | 스와이프 + **이전/다음(56px)** + 01/04 위치표시 | 양쪽 핵심 정보가 한눈에 보이는 2열 카드 (불필요한 슬라이더 미도입) |
| 상담 | 어떤 화면에서든 1탭 전화 링크 | 고정 헤더/본문 CTA |
| 모션 | 일회성/저강도, 자동 카드 전환 없음 | 짧은 피드백, reduced motion 대응 |
| 접근성 | 명료한 한글 레이블, 키보드 작동, visible focus | 동일 |

## 3. 상세 변경점
1. 모바일 메인 카드 설명·제목·번호 및 상세 페이지 설명 17–20px 중심 확대
2. 프로그램 카드 본문 18px, 버튼은 화살표만 쓰지 않고 `← 이전 / 다음 →`으로 표시
3. 작고 클릭하기 어려운 도트 내비게이션은 숨기고, 명시적 이전·다음/카드 순서(01/04)를 유지
4. 이용 안내 아코디언의 행 높이 60px, 설명 17px
5. 모바일 상담 하단 고정 CTA 높이 60px, 보조 안내문 13px
6. 데스크톱 내비게이션 17px, 헤더 상담 버튼 56px, 주요 본문 18–19px
7. 키보드 초점 표시 강화, 자동/반복 모션 추가하지 않음

## 4. 기술/콘텐츠 구분
- 전문 프로그램의 실제 제공 범위, 담당자 자격, 장기요양 급여 안내 등은 운영 자료에 따라 최종 공개 문구 조정
- `CENTER_CONFIG.centerPhone`은 현재 **빈 값**. 시안 링크는 기존 다앤유 방문재활 대표번호 `02-6953-5776` 연결이며 센터 전용번호가 아님
- `CENTER_CONFIG.centerAddress`, `CENTER_CONFIG.centerHours`도 미확정. 지도는 주소 확정 후 연결
- CDN 공식 로고가 접속 불가할 경우 임시 텍스트 fallback 노출. 배포용에는 공식 원본 다운로드/내장 권장

## 5. QA 수용 기준
- 320/360/390/768/1024/1440px에서 가로 넘침 없음
- 모바일 3가지 버튼 모두 화면 전환 동작, 뒤로 가기/복귀 동작
- 프로그램 이전/다음, 순서 표기, 스와이프, 화살표 키보드 사용 가능
- 모바일 1탭 / 데스크톱 1탭 상담 링크 접근, 모든 위치에서 3클릭 이내
- 주요 CTA의 조작 영역, 명도 대비, `prefers-reduced-motion` 확인
- 브라우저 200% 확대/실사용자 테스트 및 실기기 통화 호출은 운영 전 추가 확인
