# 강서 다앤유 랜딩페이지 설계 결정

## 포지셔닝
- 기존 다앤유(DA&YOU)의 재활 전문성에서 확장한 데이케어센터
- 운동센터처럼 보이지 않는 **편안한 하루의 돌봄**을 우선 표현
- 차별화: 식이·연하 기능 지원과 LSVT BIG 기반 움직임·균형 프로그램
- 공식 로고: 2025년 11월 업로드 다앤유 원본 사용. 생성형 이미지에 묘사된 유사 로고 사용 금지

## 사용자·경험
- 모바일·데스크톱 모두 50대 이상 보호자를 주요 이용자 **가설**로 설정
- 세 가지 내적 질문: 신뢰할 수 있는가 / 부모님께 적합한가 / 이용할 수 있는가
- 질문을 FAQ로 직접 나열하지 않고 정보구조와 기능으로 해소
- 모바일: 다앤유 소개 / 전문 프로그램 / 이용 안내의 3개 진입 영역
- 프로그램: 카드 직접 넘기기, 명시적 이전·다음, 페이지 수 제공, 자동 전환 없음
- 데스크톱: 편집형 랜딩 구조 유지
- 상담: 상시 접근, 1탭 우선, 모든 주요 경로 최대 3클릭
