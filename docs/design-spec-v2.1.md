# 데스크톱 Hero 재설계 v2.1

## 1. 설계 배경

현재 v2.0 Hero는 1980×1080 모니터에서 콘텐츠 최대 폭이 좁고 중앙 이미지가 한 장으로 합쳐져 있어, 레퍼런스의 넓고 밀도 높은 4열 편집 구성이 충분히 드러나지 않는다.

v2.1은 다음 세 가지 요구를 우선한다.

1. 1980×1080을 대표 데스크톱 해상도로 삼아 첫 화면의 가로·세로 공간을 적극 사용한다.
2. 1열은 카드로 감싸지 않고 배경 위에 문장과 상담 동선을 직접 배치한다.
3. 중앙 2개 열은 서로 구분되는 대표 사진 카드 두 장으로 구성한다.

모바일 랜딩은 현재 승인된 구조와 디자인을 유지한다. 이번 설계 범위는 데스크톱 및 태블릿 전환 구간의 Hero다.

## 2. 목표 인상

- 재활 전문성과 일상의 따뜻함이 같은 비중으로 보인다.
- 1980px 화면에서 축소된 웹페이지가 아니라 화면을 채우는 편집형 랜딩으로 보인다.
- 중앙의 두 사진만 보아도 `일상 돌봄`과 `재활 활동`이라는 다앤유의 두 축을 이해할 수 있다.
- 오른쪽 메뉴는 스마트폰 홈 화면의 큰 버튼처럼 직관적으로 누를 수 있어야 한다.
- 카드가 많아 보이지 않도록 1열은 열린 공간으로 남기고, 사진과 메뉴에만 명확한 표면을 부여한다.

## 3. 1980×1080 기준 캔버스

| 항목 | 기준값 | 의도 |
| --- | --- | --- |
| 대표 QA 뷰포트 | 1980×1080 | 기본 데스크톱 기준 |
| Hero 최대 폭 | 1780px | 좌우 100px 안팎의 여백 확보 |
| Hero 유동 폭 | `calc(100vw - 96px)` | 1980px 미만에서도 48px 측면 여백 유지 |
| 헤더 높이 | 88px | 브랜드와 Hero를 한 화면에 수용 |
| Hero 본문 높이 | 820~880px | 브라우저 UI를 제외한 화면에서도 주요 내용이 잘리지 않도록 조정 |
| 열 간격 | 20px | 두 대표 사진을 독립된 카드로 인식 |
| 카드 모서리 | 28~34px | 현재 모바일의 부드러운 조형 언어 계승 |

Hero만 넓은 캔버스를 사용한다. 이후 본문 섹션은 가독성을 위해 기존 1180px 안팎의 콘텐츠 폭을 유지한다. 헤더의 내부 폭은 Hero와 같은 1780px 기준으로 맞춰 좌우 기준선을 통일한다.

## 4. 데스크톱 구조

```text
┌──────────────────────────── 1~3열 제목/메시지 ────────────────────────────┬── 4열 안내 ──┐
│ 재활의 전문성을 일상의 돌봄으로.                                         │ QUICK MENU    │
├───────────────┬────────────────────────┬────────────────────────┬───────────────┤
│ 1열           │ 2열                   │ 3열                   │ 4열           │
│ 열린 카피 영역 │ 대표 사진 A            │ 대표 사진 B            │ 대형 메뉴 01    │
│               │ 일상의 돌봄            │ 재활 전문성            │ 대형 메뉴 02    │
│ 설명·키워드    │                        │                        │ 대형 메뉴 03    │
│ 상담 CTA       │                        │                        │               │
└───────────────┴────────────────────────┴────────────────────────┴───────────────┘
```

권장 열 비율은 `0.82fr 1.08fr 1.08fr 0.92fr`이다. 1열은 여백과 문장이 중심이고, 중앙 두 열은 같은 폭으로 균형을 맞추며, 4열은 한글 메뉴 제목이 두 줄로 꺾이지 않을 폭을 확보한다.

## 5. 열별 상세 설계

### 1열 — 카드 없는 편집형 카피

1열에는 배경색, 외곽선, 둥근 모서리, 그림자를 적용하지 않는다. 전체 Hero의 밝은 배경 위에 다음 요소를 직접 배치한다.

- 작은 영문 키커: `BEGIN A BETTER DAY`
- 제목: `평범한 하루 전체를 바라봅니다.`
- 설명: 식사, 움직임, 관계와 휴식까지 연결해 보는 다앤유의 관점을 2~3문장으로 전달한다.
- 키워드: `식사`, `움직임`, `인지`, `일상`
- 하단 상담 CTA: `이용 상담하기`

제목은 36~44px, 본문은 17~18px로 설정한다. CTA는 열 하단에 고정해 중앙 사진 카드의 하단 기준선과 맞춘다. 키워드는 작은 태그로 사용할 수 있지만 1열 전체가 카드처럼 보이는 표면은 만들지 않는다.

### 2열 — 대표 사진 A: 일상의 돌봄

- 소스: 현재의 `media.hero`
- 역할: 어르신이 편안하게 관계를 맺는 하루와 생활 공간을 보여준다.
- 하단 오버레이 제목: `편안한 하루, 함께하는 돌봄`
- 상태 표기: 실제 센터 사진이 확정되기 전까지 `콘셉트 이미지`를 명시한다.

사진은 열 전체 높이를 사용하는 세로형 카드로 자르고, 인물의 얼굴이 가려지지 않도록 데스크톱 전용 `object-position`을 지정한다. 텍스트 가독성을 위해 하단에만 짙은 그라디언트를 제한적으로 사용한다.

### 3열 — 대표 사진 B: 재활 전문성

- 소스: 현재의 `media.movement`
- 역할: 단순 여가가 아니라 목적 있는 움직임과 재활 활동을 보여준다.
- 하단 오버레이 제목: `움직임을 일상과 연결합니다.`
- 상태 표기: 실제 센터 사진이 확정되기 전까지 `콘셉트 이미지`를 명시한다.

2열과 같은 카드 크기를 사용하되 서로 다른 `object-position`과 오버레이 농도를 적용한다. 2열은 밝고 따뜻한 톤, 3열은 청록·네이비 계열의 조금 더 선명한 톤으로 역할을 구분한다. 두 사진 사이에는 20px의 빈 간격을 유지하며 하나의 합성 이미지처럼 붙이지 않는다.

### 4열 — 스마트폰형 대형 메뉴

4열은 `QUICK MENU` 안내와 세 개의 큰 링크를 세로로 배치한다.

1. `01 / ABOUT` — 다앤유 소개
2. `02 / PROGRAM` — 전문 프로그램
3. `03 / VISIT` — 이용 안내

각 메뉴는 약 180~210px 높이로 설정하고 번호, 제목, 한 줄 설명, 화살표를 포함한다. 카드 전체가 클릭 영역이며, 포인터·키보드 포커스 시 3~4px 상승하고 화살표가 이동한다. 세 메뉴의 색 대비는 기존 브랜드 팔레트 안에서 `화이트 → 네이비 → 스카이` 순으로 유지해 목적지를 빠르게 구분한다.

## 6. 제목과 정보 위계

- Hero 대표 제목: 72~82px, 행간 1.02~1.06, 최대 두 줄
- 1열 소제목: 36~44px
- 사진 오버레이 제목: 32~40px
- 퀵 메뉴 제목: 28~32px
- 본문: 17~18px
- 영문 키커·번호: 11~13px, 자간을 넓게 적용

큰 제목은 1~3열 상단을 사용하되 중앙 사진의 시작 지점을 지나치게 아래로 밀지 않는다. `재활의 전문성을`과 `일상의 돌봄으로.` 사이의 색상 대비는 기존 다앤유 청록색 포인트를 유지한다.

## 7. 반응형 전환

| 화면 폭 | 구성 |
| --- | --- |
| 1600px 이상 | 1780px 한도 내의 완전한 4열 구성. 제목과 본문을 첫 화면 안에 수용 |
| 1280~1599px | 측면 여백 32px, 4열 유지. 글자와 메뉴 높이를 한 단계 축소 |
| 1024~1279px | 1열 카피와 중앙 사진 두 장을 우선 배치하고, 퀵 메뉴 3개는 하단 가로 행으로 전환 |
| 851~1023px | 카피 다음에 사진 두 장을 2열로 배치하고 메뉴는 하단 행으로 유지 |
| 850px 이하 | 현재 승인된 모바일 전용 랜딩을 그대로 사용 |

1024px 이하에서도 대표 사진 두 장의 의미가 사라지지 않아야 한다. 공간이 부족하다는 이유로 한 장을 숨기거나 다시 하나의 이미지로 합치지 않는다.

## 8. 움직임과 상호작용

- 사진 카드 진입: 투명도와 12px 이하의 짧은 상승 모션
- 사진 카드 호버: 이미지 배율 최대 1.015, 오버레이 텍스트 2px 상승
- 메뉴 호버·포커스: 카드 3~4px 상승, 화살표 우상향 이동
- 스크롤: 화면 중앙에 가까운 사진과 메뉴의 대비를 아주 작게 강화
- `prefers-reduced-motion: reduce`: 이동과 확대를 제거하고 색·외곽선 변화만 제공

움직임은 클릭 가능성과 정보 위계를 알리는 데만 사용하며, 자동 반복이나 큰 패럴랙스는 적용하지 않는다.

## 9. 사진 교체 원칙

현재 두 장은 레이아웃과 분위기 검증을 위한 콘셉트 이미지다. 실제 센터 사진을 제공받으면 다음 조건으로 교체한다.

- A: 자연광이 있는 공용 공간에서 어르신과 직원이 함께 있는 장면
- B: 물리·작업·인지 활동 중 한 가지를 구체적으로 수행하는 장면
- 두 사진 모두 초상권 사용 동의와 웹 게시 허가 확인
- 3:4에 가까운 세로 크롭에서도 핵심 인물이 남는 원본 사용
- 대체 텍스트는 장면을 사실적으로 설명하고 홍보성 수식어를 넣지 않음

## 10. 구현 승인 기준

- [x] 1980×1080에서 Hero와 헤더가 화면 폭을 충분히 사용한다.
- [x] 1열에 카드 배경, 외곽선, 그림자가 없다.
- [x] 중앙 2열에 서로 다른 대표 사진 두 장이 독립 카드로 보인다.
- [x] 두 사진에 콘셉트 이미지 상태가 명확히 표시된다.
- [x] 4열의 메뉴 세 개가 한눈에 클릭 가능한 큰 버튼으로 보인다.
- [x] 1980×1080에서 Hero 핵심 내용이 첫 화면에 잘리지 않는다.
- [x] 1980×1080, 1440×900, 1024×768, 851px에서 가로 넘침이 없다.
- [x] 1024×768과 851px 경계에서 대표 사진 두 장과 메뉴가 모두 유지된다.
- [x] 850px 이하에서 별도의 v2.2 모바일 랜딩으로 전환된다.
- [x] 키보드 포커스와 `prefers-reduced-motion` 대응을 유지한다.

## 11. 이번 단계의 제외 범위

- 실제 센터 사진이 제공되기 전의 최종 사진 확정
- 센터 공식 전화번호, 주소, 운영시간 확정
- Hero 이후 본문 섹션의 전면 재설계
- 승인된 모바일 랜딩의 구조 변경
