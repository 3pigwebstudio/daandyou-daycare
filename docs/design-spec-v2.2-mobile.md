# 모바일 홈 재설계 v2.2

## 1. 설계 결정

현재 모바일 홈의 비대칭 카드, 겹친 외곽선, 글래스 표면과 `보기` 배지는 장식적이지만 50대 이상 보호자에게는 화면이 흔들리거나 복잡하게 보일 수 있다.

v2.2는 유튜브 모바일 피드의 익숙한 화면 질서를 참고한다. 각 메뉴를 화면 폭에 가까운 동일한 16:9 카드로 쌓고, 형태와 간격을 반복해 안정감을 만든다. 다앤유의 청록·네이비·스카이 색감은 유지한다.

## 2. 변경 원칙

### 제거

- 카드 우측 상단의 `보기` 배지
- 카드 뒤에 겹쳐진 흰색 외곽 프레임
- 비대칭 모서리와 카드별 좌우 들여쓰기
- 글래스모피즘, `backdrop-filter`, 반투명 블러
- 스크롤 위치에 따른 카드 확대·강조
- 포인터 위치에 따른 3D 기울기와 광택 효과
- 큰 부유 그림자와 장식용 방사형 배경

### 유지

- 다앤유 소개: 청록 `#3985AB`
- 전문 프로그램: 네이비 `#193249`
- 이용 및 위치 안내: 스카이 `#6CB5D4`
- 세 메뉴에서 상세 화면으로 이동하는 현재 정보 구조
- 화면 하단의 `이용 상담하기` 고정 CTA
- 850px 이하 모바일 전용 화면 체계

## 3. 모바일 홈 구조

```text
┌──────────────────────────┐
│ 다앤유 로고              │  불투명 헤더
├──────────────────────────┤
│ ┌──────────────────────┐ │
│ │ 01 / 다앤유 소개   ↗ │ │
│ │                      │ │  16:9
│ │ 다앤유 소개          │ │
│ │ 전문성과 신뢰        │ │
│ └──────────────────────┘ │
│                          │  12px
│ ┌──────────────────────┐ │
│ │ 02 / 프로그램      ↗ │ │
│ │                      │ │  16:9
│ │ 전문 프로그램        │ │
│ │ 어르신의 다양한 활동 │ │
│ └──────────────────────┘ │
│                          │  12px
│ ┌──────────────────────┐ │
│ │ 03 / 이용 안내     ↗ │ │
│ │                      │ │  16:9
│ │ 이용 및 위치 안내    │ │
│ │ 이용·위치·상담       │ │
│ └──────────────────────┘ │
├──────────────────────────┤
│      이용 상담하기       │  불투명 고정 CTA
└──────────────────────────┘
```

별도의 큰 소개 문구는 홈 상단에서 제거한다. 로고 바로 아래에 세 메뉴가 시작되도록 해 사용자가 첫 화면에서 목적지를 즉시 이해하게 한다. 브랜드 설명은 각 상세 화면에서 충분히 제공한다.

## 4. 화면과 비율

| 항목 | 기준 |
| --- | --- |
| 모바일 적용 범위 | 850px 이하 |
| 홈 최대 폭 | 600px |
| 좌우 여백 | 12px, 360px 이하에서는 10px |
| 카드 폭 | `100%` |
| 카드 비율 | `aspect-ratio: 16 / 9` |
| 카드 간격 | 12px |
| 모서리 | 모든 카드 동일한 18px |
| 헤더 높이 | 72~74px |
| 하단 안전 여백 | 고정 CTA 높이 + `env(safe-area-inset-bottom)` |

390px 화면에서는 카드의 실제 콘텐츠 폭이 약 366px, 높이가 약 206px가 된다. 430px 화면에서는 약 406×228px로 확장된다. 고정 높이를 사용하지 않아 화면 폭에 따라 같은 비율로 자연스럽게 커진다.

## 5. 카드 내부 구성

모든 카드는 동일한 패딩과 동일한 텍스트 위치를 사용한다.

- 상단 왼쪽: 메뉴 번호와 분류
- 상단 오른쪽: 테두리나 배경이 없는 단순 화살표 `↗`
- 하단 왼쪽: 메뉴 제목과 한 줄 설명
- 카드 전체: 하나의 링크 및 터치 영역

권장 타이포그래피:

| 요소 | 크기 | 기준 |
| --- | --- | --- |
| 번호·분류 | 13px | 굵기 700, 자간 0.08em |
| 메뉴 제목 | 30~34px | 굵기 800, 행간 1.2 |
| 한 줄 설명 | 16~17px | 굵기 600, 행간 1.45 |
| 화살표 | 25~28px | 최소 44×44px 영역 안에 배치 |

3번 스카이 카드에는 네이비 글자를 사용하고, 1·2번 카드에는 흰 글자를 사용한다. 긴 제목인 `이용 및 위치 안내`는 390px 이상에서 한 줄을 우선하되, 360px에서만 두 줄을 허용한다.

## 6. 클릭 가능성 표현

`보기` 배지는 제거하지만 다음 단서로 카드가 링크임을 알린다.

- 세 카드 모두 같은 위치에 우상향 화살표 배치
- 카드 전체에 손가락·포인터 입력 영역 제공
- 키보드 포커스 시 3px 황금색 외곽선 표시
- 터치 시 배경을 약 6% 어둡게 변경
- 터치 축소는 최대 `scale(.995)`로 제한하거나 생략
- 상세 화면에서 같은 위치의 `메인으로` 버튼 제공

스크롤만 해도 카드가 확대되거나 빛나는 효과는 사용하지 않는다. 화면이 움직이지 않아도 정보 위계와 조작 방법을 이해할 수 있어야 한다.

## 7. 글래스 효과 제거 범위

### 헤더

- 배경: `#FFFFFF` 또는 `#F7F8F9` 100% 불투명
- `backdrop-filter` 제거
- 하단 1px 구분선만 사용
- 그림자는 사용하지 않거나 매우 약한 고정 그림자만 사용

### 메뉴 카드

- 단색 배경 사용
- 가상 요소로 만든 겹친 프레임 제거
- 반투명 테두리, 내부 광택, 방사형 하이라이트 제거
- 동일한 18px 모서리와 1단 표면만 사용

### 하단 상담 CTA

- 외부 글래스 캡슐 제거
- 화면 전체 폭의 불투명 흰색 바에 상단 1px 구분선 적용
- 내부 상담 버튼은 기존 청록색을 유지
- 버튼 모서리는 14px, 높이는 최소 56px
- 임시 대표번호 안내 문구는 버튼 아래에 읽을 수 있는 12px로 유지

## 8. 배경과 간격

- 모바일 홈 배경은 단색 `#F7F8F9`를 사용한다.
- 방사형 장식 그라디언트는 제거한다.
- 로고와 첫 카드 사이 12px
- 마지막 카드와 하단 설명 사이 16px
- 마지막 카드가 고정 CTA에 가려지지 않도록 하단 패딩을 CTA 높이보다 24px 크게 확보한다.
- 카드 가장자리는 화면 좌우 기준선과 정확히 맞춘다.

## 9. 상세 화면과의 연결

이번 변경의 중심은 모바일 홈이지만, 홈과 상세 화면 사이의 시각적 이질감을 줄이기 위해 상세 화면에서도 다음 원칙을 함께 적용한다.

- 사진과 콘텐츠 카드의 모서리를 18~20px 범위로 통일
- 불필요한 글래스·블러 제거
- 본문 크기 17px 유지
- `메인으로`, 이전·다음, FAQ의 터치 높이 최소 48px 유지
- 실제 사진과 콘셉트 이미지는 현재처럼 명확히 구분

프로그램 슬라이더, FAQ, 위치 안내의 기능과 콘텐츠 순서는 바꾸지 않는다.

## 10. 접근성과 사용성

- 각 카드 링크의 접근 가능한 이름은 제목과 목적지를 포함한다.
- 색상만으로 카드 목적을 구분하지 않고 번호·제목을 함께 제공한다.
- 텍스트와 배경은 WCAG AA 대비를 만족한다.
- 카드를 눌렀을 때의 상태 변화는 150ms 이내로 짧게 적용한다.
- `prefers-reduced-motion`에서는 모든 이동·축소 효과를 제거한다.
- 200% 확대에서 가로 스크롤 없이 제목과 화살표가 겹치지 않아야 한다.

## 11. 구현 승인 기준

- [ ] 홈 카드 3개에서 `보기` 배지가 완전히 제거된다.
- [ ] 헤더, 카드, 하단 CTA에 `backdrop-filter`와 글래스 표면이 없다.
- [ ] 세 카드가 모두 같은 16:9 비율과 같은 18px 모서리를 사용한다.
- [ ] 카드별 좌우 들여쓰기, 회전, 겹친 외곽선이 없다.
- [ ] 카드가 좌우 12px 여백을 제외한 화면 폭을 채운다.
- [ ] 청록·네이비·스카이 브랜드 색상은 유지된다.
- [ ] 화살표와 전체 카드 링크로 클릭 가능성을 이해할 수 있다.
- [ ] 고정 상담 CTA가 마지막 카드를 가리지 않는다.
- [ ] 360×800, 390×844, 393×852, 430×932에서 가로 넘침이 없다.
- [ ] 200% 확대와 키보드 포커스에서 모든 메뉴를 사용할 수 있다.
- [ ] 데스크톱 v2.1 Hero 설계에는 영향을 주지 않는다.
