# v2.7 프로그램 사진 레이아웃 보정

## 문제

`식이·연하 지원`과 `생활·건강·정서 지원`의 원본 사진은 인물과 활동 맥락이 좌우로 펼쳐진 가로 구도다. 기존 카드에서는 사진을 좁은 세로 띠로 사용해 식판, 지원 인력, 두 어르신의 상호작용이 충분히 보이지 않았다.

## 해결

- 핵심 사진 카드 2개를 12열 그리드 중 5열 폭으로 확장한다.
- 사진을 카드 좌측의 세로 띠가 아니라 카드 상단의 200px 가로 프레임에 배치한다.
- `식이·연하 지원`은 어르신, 지원 인력과 식판이 함께 보이도록 초점을 조정한다.
- `생활·건강·정서 지원`은 두 어르신과 활동 도구가 함께 보이도록 중앙 구도를 유지한다.
- 나머지 2개 카드는 3열의 작은 카드로 유지해 정보 위계와 리듬을 만든다.
- 851~1100px 구간에서도 핵심 사진 카드만 상단 220px 프레임을 유지한다.

## 기대 효과

프로그램 이름을 읽기 전에 사진만으로도 `식사 지원`과 `함께하는 신체·정서 활동`의 실제 맥락을 파악할 수 있다.
