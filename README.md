# 강서 다앤유 재활 데이케어센터

3PIG에서 제작하는 강서 다앤유(DA&YOU) 재활 데이케어센터 홍보형 랜딩페이지입니다.

## 설계 기준

- **현재 기준 시안:** v1.6 (50대 이상 보호자 중심 모바일·데스크톱 UX)
- **브랜드:** 기존 다앤유 공식 마스터 로고(2025년 11월 업로드 버전) 계승
- **모바일:** 다앤유 소개 / 전문 프로그램 / 이용 안내의 3가지 진입 메뉴
- **데스크톱:** 편집형 랜딩페이지
- **전문 프로그램:** 식이·연하 관련 지원과 LSVT BIG 기반 움직임 프로그램
- **사용자 흐름:** 신뢰 형성 → 서비스 적합성 판단 → 이용 안내 → 연락
- **연락 UX:** 모든 주요 경로에서 3클릭 이내 상담 접근
- **UI 팔레트:** Primary `#206E88`, Navy `#193249`, Sky `#D8EAF3`, Charcoal `#27343B`
- **배포 검토:** Cloudflare (Pages 또는 Workers 방식 미확정)

## 프로젝트 상태

이 저장소는 **Private** 프로젝트입니다. 운영 사이트로 배포하지 않았습니다. 랜딩페이지 v1.6 HTML 및 이미지 파일은 작업 패키지로 준비되어 있으며 저장소 업로드 대상입니다.

### 운영 배포 전 필수 확인

1. 강서 센터 공식 전화번호와 주소 설정
2. 승인된 다앤유 공식 마스터 로고 원본 파일 확보
3. 재활 프로그램·운영 안내 문구 최종 확인
4. 실제 휴대전화 상담 연결 및 브라우저 확대·접근성 검증
5. v1.7 여백 및 정렬 QA 개선
